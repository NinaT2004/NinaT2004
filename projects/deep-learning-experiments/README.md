# Deep learning experiments

- **Sequence modelling** — compared input window sizes for airline passenger forecasting. For sentiment classification, the LSTM with pretrained GloVe embeddings reached **79.6% test accuracy** in the reported experiment. I also examined how sampling temperature changes character- and word-level generation.
- **Image generation** — compared MNIST reconstruction with and without KL regularization in a VAE. In a separate image translation task, the MAE baseline had lower pixel error than the conditional GAN, while the conditional GAN produced sharper examples in the report.
- **Reinforcement learning** — compared SARSA and Q-learning using reward, policy entropy, and temporal-difference error. Q-learning reached higher reported reward in the coursework runs.

These results describe the coursework experiments.
