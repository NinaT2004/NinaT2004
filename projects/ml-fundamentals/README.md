# Machine learning fundamentals

## Implementation coursework

- **Linear regression** — implemented gradient descent with NumPy and tracked mean squared error as the weights converged on the scikit-learn diabetes dataset.
- **Nonlinear feature transformations and logistic regression** — explored feature mappings and classification.
- **Support vector machines** — varied the penalty parameter and examined its effect on the separating boundary, margin violations, and support vectors.
- **k-nearest neighbours** — investigated instance-based classification.

## Theory coursework

Written exercises cover linear separability, perceptron updates, VC dimension, support vector machines, and the k-means objective.
